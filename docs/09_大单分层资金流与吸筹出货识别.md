# 09 大单分层资金流与吸筹出货识别 — 产品开发技术方案

## 1. 目标与定位

最接近 Level-2“主力大单”且**全市场可覆盖**的功能：
- 超大单 / 大单 / 中单 / 小单四层净流入实时拆解；
- 大单成本带；
- 吸筹 / 出货 / 拉升三态识别。

优先级：P0。数据已在 `principal_capital` 库里，改动最小、实操性最强。

## 2. 产品方案

### 2.1 页面模块
- 分层资金流榜：按 `smart_ratio` 排序，全主板覆盖。
- 个股资金分层：超大 / 大 / 中 / 小净流入与占比。
- 状态标签：吸筹 / 出货 / 拉升。

### 2.2 输出口径
- `super_ratio = super_net / total_amount`。
- `big_ratio = big_net / total_amount`。
- `smart_ratio = (super_net + big_net) / total_amount`。
- 大单成本带 = Σ(大单成交额) / Σ(大单成交量)。

## 3. 技术方案

### 3.1 数据源
- 东财 `eastmoney.py` 字段：`f66 超大单净 / f72 大单净 / f78 中单净 / f84 小单净`。
- 新浪 `sina.py`：`r0/r1/r2/r3_in/out` 兜底。
- 全市场快照沿用 `principal_capital` 多源与熔断。

### 3.2 状态机

用 `price_change` 与 `smart_ratio` 二维判断（阈值进 config）：
- 吸筹：大单净买 + 价格横盘 / 微跌；
- 出货：大单净卖 + 价格横盘 / 微涨；
- 拉升：大单净买 + 价格上行。

状态机与 `smart_money_radar` 四阶段同构，可复刻迁移逻辑。

### 3.3 调度
- 盘中每 5 分钟一轮（沿用 principal-capital-scan）。

## 4. 数据存储方案

```sql
CREATE TABLE tier_flow_snapshot (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,
  hhmm TEXT NOT NULL,
  code TEXT NOT NULL,
  name TEXT,
  super_net REAL,
  big_net REAL,
  mid_net REAL,
  small_net REAL,
  smart_ratio REAL,
  vwap_large REAL,
  state TEXT
);
CREATE INDEX idx_tier_flow ON tier_flow_snapshot(date, hhmm);
CREATE INDEX idx_tier_flow_code ON tier_flow_snapshot(code, date);
```

快照：`reports/tier_flow_latest.json` + `reports/data_backend/tier_flow_latest.json`。

## 5. 数据读取方案

- `GET /api/v1/principal-capital/tier-flow/latest`：读 JSON，秒开。
- `GET /api/v1/principal-capital/tier-flow/{code}`：走 `idx_tier_flow_code`。
- 页面显示数据源与滞后提示，缓存降级标注分钟级滞后。

## 6. 与现有系统集成

- 在 `backend/plugins/principal_capital/` 内扩展，不另起数据源。
- 复用 `multi_source.fetch_market_fund_flow_resilient` 与 `_base_filter`。
- 状态标签可回填 `principal_capital` 报告，供雷达观察池与主筛选加分。

## 7. 测试与验收

- 分层比例计算测试：total_amount = 0 防除零。
- 状态机迁移测试：吸筹 / 出货 / 拉升边界。
- 验收：全主板覆盖 > 5000 只，5 分钟级刷新，页面 < 500ms。

## 8. 上线与运维

- 并入 principal-capital-scan 自循环。
- 生成物提交 `data-snapshots`。

## 9. 风险与限制

- 东财 / 新浪大单口径不完全一致，需在报告中标注 active_source。
- 大单成本带是估算值，非精确成交分布（精确分价见 11）。

## 10. 里程碑

1. M1：分层字段扩展 + 落库。
2. M2：smart_ratio + 大单成本带。
3. M3：吸筹 / 出货 / 拉升状态机 + 页面。
