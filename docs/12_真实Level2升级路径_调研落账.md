## 2. 三个关键事实（决定方案可行性）

### 2.1 免费栈给不了「真实逐笔方向」，QMT L2 给得了
- 本项目 07/08/13 用的 pytdx：免费、五档、逐笔**无毫秒时间戳**、无委托方向分类。
- QMT L2 逐笔委托/逐笔成交带**精确时间与买卖方向**，可自算「超大/大/中/小单」资金流分类——这是对东财/新浪「估算口径」资金流的**根上替代**（前几轮 grill 的结论）。

### 2.2 沪市免费、深市收费 → 存在「半免费」组合
- 若只想先验证链路：**只开沪市 L2（0 元）+ 深市继续用免费栈近似**，即可把整套采集/落盘/特征链跑通，之后再决定是否花 ~30 元/月补深市。
- 全 A 股「主力行为选股」最终形态需要两市 L2 → 月成本约一杯咖啡钱。

### 2.3 Mac 是最大隐性成本（比深市月费更值得提前决策）
- QMT 无 macOS 原生版。三个选项：
  1. **Parallels/UTM 虚拟机**：一次性软件费（Parallels 数百元），QMT 常驻虚拟机内，miniQMT 端口转发到 macOS 侧采集；
  2. **Windows 小主机/云机**（约 40–80 元/月）：QMT 跑远程，采集端也放远程，快照经 git/SSH 同步回本仓库；
  3. **券商云 QMT 托管**：部分券商免费/低价提供，省载体但策略环境受托管限制。
- 本项目已有本地 pytdx daemon 生态，推荐**选项 1 或 2**（与现有 launchd/cron 体系兼容）。

## 3. 落账建议（决策树）

| 场景 | 建议 |
|---|---|
| 不接受任何月费 | 维持免费栈（pytdx + HTTP 资金流），QMT L2 不启动；但可只开**沪市 L2（0 元）**做链路验证 |
| 接受 ~30 元/月 + 一次性载体 | **启动 QMT L2**：沪市全量 + 深市 L2，按 12 方案 M1→M3 施工 |
| 想彻底摆脱券商/载体 | 不存在免费路径：深市 L2 在任何券商体系内都收费；「同花顺/东财 L2 订阅」同为月费且**无程序化 API**、禁止再分发，不如 QMT |

## 4. 下一步验证清单（确认后我才建议动工 M2）

1. 联系 2–3 家券商（建议含已开户券商），书面确认：QMT 权限资金门槛、深市 L2 月费、沪市 L2 开通条件、是否支持 miniQMT 常驻、是否提供云 QMT；
2. 确认 macOS 载体选型（虚拟机 vs 云机）；
3. 开通后按 12 方案 §7 跑连通性测试：十档/逐笔/委托队列字段完整性 + 与券商客户端同屏比对；
4. 验证后按 12 方案 M2 施工 l2_feed 采集端（Parquet 本地落盘 + 聚合快照），免费栈继续跑不替换。
