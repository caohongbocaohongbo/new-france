## 四、未测试项与原因汇总

以下项为**实盘依赖**，本地离线无法验收，需交易日 9:15–9:30 窗口 + 真实行情源 + 网络：

| 未测试项 | 原因 |
|---|---|
| `probe.py` / `collector.py` 实盘拉取腾讯竞价报文 | 需交易日 9:15–9:25 竞价窗口 + 国内网络 + 真实行情源 |
| 腾讯字段语义取证（虚拟参考价/五档/9:25 最终价量） | 需对照可靠终端，至少 2 个完整交易日 |
| `finalize_once` 9:25 后最终撮合确认实盘路径 | 需 9:25 后真实最终价量可得 |
| `market_sampler.py` 全市场约 3000 只采样 | 需竞价窗口 + 全市场资金流源可用 |
| 邮件实际发送（SMTP） | 需 `SMTP_USER/SMTP_PASSWORD/SMTP_TO` 配置 + 真实收件箱 |
| `scheduler.py` daemon 长跑 | 需交易日窗口 + 本地常驻 |
| `outcomes.py` 盘后回填 | 需当日 `auction_candidates` 落库 + 历史 K 线源 |
| 产池实盘（`--run-low-position-once`） | 需全市场资金流 + 130 日 K 线源 |
