## 1. 目标与定位

每个交易日收盘后，从全市场主板筛选出 **筹码高度集中 + 获利盘 > 70% + 现价在成本带上方（趋势向上）** 的强势筹码形态股票，作为"主力已控盘、趋势健康"的关注池。逻辑是：筹码集中（主力吸筹完成）+ 获利盘高且趋势向上（成本在下方、价格向上）= 后续延续概率高。

与现有功能的区别：
- 11 分价成交（volume_profile）提供 VWAP/POC/获利盘比例的**数据**，21 是把这些数据升级为**选股**（集中度 + 获利盘 + 趋势确认）。
- 与 16 低位涨停（低位反转）互补，21 是"筹码健康、趋势向上"的顺势选股。

优先级：**P1（云端盘后 + 本地盘后，扩展 volume_profile）**。

### 2.5 综合分

**chip_score（0-100，供排序）**：
```
chip_score = concentration_strength × 40 + profit_strength × 40 + trend_strength × 20
- concentration_strength: 集中度（越小越强，0.15 → 0 分，0.05 → 满分）
- profit_strength: 获利盘比例（70% → 0 分，90% → 满分）
- trend_strength: MA20 上行斜率（趋势越强分越高）
```

### 2.6 输出口径
每只入选票输出：
- 筹码数据：`concentration_ratio`（集中度）、`p05 / p50 / p95`（成本区间分位价）、`main_cost_band`（主力成本带）
- 获利盘数据：`profit_ratio`（获利盘%）、`trapped_ratio`（套牢盘%）
- 趋势数据：`ma20`、`ma20_slope`（MA20 斜率）、`price_vs_cost`（现价相对成本带中心的位置）
- 命中标记：`concentrated`（0/1）、`high_profit`（0/1）、`trend_up`（0/1）、`tight_control`（0/1）
- 综合分：`chip_score`
- 基础面：`price / name / change_pct / total_amount`

### 3.2 指标算法（纯函数，无前视）

> ⚠️ 施工前必须完成 §0.1 的接口验证，确认数据源后再实现以下函数。

**90% 成本区间（concentration_ratio，算法已明确）**：
```python
def concentration_ratio(distribution: list) -> tuple:
    sorted_dist = sorted(distribution, key=lambda r: r["price_level"])
    total = sum(r["volume"] for r in sorted_dist)
    if total <= 0:
        return None, None, None, None
    cum = 0.0
    p05 = p50 = p95 = None
    for r in sorted_dist:
        cum += r["volume"]
        if p05 is None and cum >= total * 0.05:
            p05 = r["price_level"]
        if p50 is None and cum >= total * 0.50:
            p50 = r["price_level"]
        if p95 is None and cum >= total * 0.95:
            p95 = r["price_level"]
    if None in (p05, p50, p95) or p50 == 0:
        return None, None, None, None
    ratio = (p95 - p05) / p50   # 90% 区间宽度 / 中心价
    return round(ratio, 4), p05, p50, p95
```

**获利盘（复用 `volume_profile.profit_ratio`）**：
```python
profit_ratio = 现价下方成本量 / 总成本量  # >70% 为强
```

**MA20 上行斜率 — 修正版（G2，off-by-one 修正）**：

原 `closes[-25:-5]` 取 19 根，修正为标准 20 根窗口：
```python
def ma20_slope(closes: list) -> tuple:
    if len(closes) < 26:
        return False, 0.0
    ma20_now  = sum(closes[-20:])   / 20      # 当日 MA20
    ma20_prev = sum(closes[-26:-6]) / 20      # 5日前 MA20（20根，终点=-6）
    slope = (ma20_now - ma20_prev) / ma20_prev if ma20_prev > 0 else 0.0
    return ma20_now > ma20_prev, round(slope, 6)
```
