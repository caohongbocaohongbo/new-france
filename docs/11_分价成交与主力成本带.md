# 11 分价成交与主力成本带（Volume Profile 近似） — 产品开发技术方案

## 1. 目标与定位

对标 Level-2“分价表 / 筹码分布”：
- 当日成交密集区、最大成交量价格、VWAP；
- 主力成本带（大单密集成交价）；
- 现价在成本带上 / 下方的位置，用于支撑 / 压力判断。

优先级：P1。盘后重算，保证查询快、口径可控。

## 2. 产品方案

### 2.1 页面模块
- 分价图：价格档位 × 成交量柱状图。
- 成本带：主力大单成本区间高亮。
- 指标卡：VWAP、最大成交量价格、获利盘 / 套牢盘比例。

### 2.2 输出口径
- VWAP = Σ成交额 / Σ成交量。
- 最大成交量价格 = 成交量最高档位。
- 获利盘比例 = 现价上方成交量 / 总成交量（近似）。

## 3. 技术方案

### 3.1 数据源
- 精确分价需要真 L2 逐笔；免费近似用：
  - pytdx 分钟 K（open/high/low/close/vol），把分钟量按经验比例分配（如 close 70%、high-low 区间 30%）；
  - 或接入东财分价 / akShare 分价接口（如可用）。
- 主力成本带用 09 方案的大单成交额 / 大单成交量近似。

### 3.2 算法
- 价格档位按 0.01 或 0.05 分桶。
- 成交量累积形成 Volume Profile。
- 主力成本带 = 大单密集成交价区间（大单量 Top 价格档的加权均值）。

### 3.3 调度
- 盘后 15:10 重算当日分价，不盘中实时计算。

## 4. 数据存储方案

```sql
CREATE TABLE price_distribution (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,
  code TEXT NOT NULL,
  price_level REAL NOT NULL,
  volume REAL,
  cumulative_ratio REAL
);
CREATE INDEX idx_price_dist ON price_distribution(date, code);
```

快照：`reports/volume_profile_latest.json`。

## 5. 数据读取方案

- `GET /api/v1/volume-profile/latest`：读快照。
- `GET /api/v1/volume-profile/{code}?date=`：走 `idx_price_dist`。
- 分价明细只在个股详情加载，Dashboard 不查。

## 6. 与现有系统集成

- 新增 `backend/plugins/volume_profile/`。
- 复用 `historical_kline` / `smart_money_radar` 的 VWAP 与 `principal_capital` 大单数据。

## 7. 测试与验收

- 分桶与累积比例计算测试。
- VWAP 与已有 `vwap_deviation` 口径一致。
- 验收：分价图与公开软件趋势一致，空数据显示空态。

## 8. 上线与运维

- 盘后重算，生成物提交 `data-snapshots`。

## 9. 风险与限制

- 分钟 K 近似分价不是真实逐笔分价，页面需标注“近似”。
- 停牌 / 集合竞价数据需过滤。

## 10. 里程碑

1. M1：分钟 K 分桶近似。
2. M2：主力成本带。
3. M3：页面 + 筹码比例。
