## 1. 目标与定位

每个交易日收盘后，从全市场主板筛选出 **平台整理后放量突破** 或 **跳空高开缺口不回补** 的股票，作为形态启动候选池。逻辑是：窄幅平台蓄势（主力吸筹整理）+ 放量突破（启动信号），或跳空缺口不回补（强势确认）= 后续上涨概率更高。

与现有功能的区别：
- 18/19 是「指标/趋势」维度（MACD/KDJ/均线），20 是「形态」维度（平台/缺口）。
- 形态识别是 A 股短线最经典的选股方式（突破平台、缺口不回补、旗形），补盲。

优先级：**P1（云端盘后、无本地依赖、K 线现成）**。

前端结构：

- tab 切换不刷新页面；数据通过 SSE 推送 + 60s 轮询实时回显。

### 2.3 页面模块（形态突破 tab 内）
- **平台突破池**：窄幅平台整理后放量突破平台上沿。
- **缺口不回补池**：跳空高开缺口（幅度 > 2%）3 日不回补。
- **🔥 双形态共振**：同时满足「平台突破 + 缺口不回补」的票，行首加 🔥 emoji 突出（与 18/19 的多命中标识一致的视觉优先级）。
- **个股详情**：平台区间标注 + 缺口标注副图（ECharts）。

### 2.4 筛选条件（默认主板，PATTERN_* env 可开创业板/科创板）

**市场过滤（复用 `common.market_filter`）**：
- 默认仅主板（剔除 300/301 创业板、688 科创板、ST）。
- `PATTERN_SHOW_GEM=1` / `PATTERN_SHOW_STAR=1` 可分别打开创业板/科创板（预留扩展，主板票仍排前）。

**平台突破（相对波动率窄幅，含 grill 优化）**：
1. **窄幅平台**：近 20 日振幅 `max(high)-min(low)` / 中心价 **< 该股近 60 日日均振幅 × 0.6**（相对窄幅，替代固定 15% 阈值）。
2. **放量突破**：今日 `量比 > 2.0` 且 `close > max(high[-20:-1])`（突破平台上沿）。

**缺口不回补（区分类型/大小，含 grill 优化）**：
1. **跳空缺口**：3 日前 `open > prev_high`（跳空高开），缺口幅度 `(open - prev_high) / prev_high > 2%`。
2. **不回补**：近 3 日 `min(low) > 缺口下沿`（缺口不回补）。
3. **突破缺口**（置信度更高）：缺口伴随放量 + 突破平台 → 单独标记 `gap_type=breakaway`。

**🔥 双形态共振**：同时满足「平台突破 + 缺口不回补」→ `dual_hit=1`，🔥 突出。

### 2.5 综合分

**pattern_score（0-100，供排序）**：
```
pattern_score = platform_strength × 40 + gap_strength × 40 + dual_bonus × 20
- platform_strength: 平台窄幅程度（越窄越强）+ 突破幅度
- gap_strength: 缺口幅度（越大越强）+ 缺口类型（突破缺口加权）
- dual_bonus: 双形态共振加分
```

### 2.6 输出口径
每只入选票输出：
- 平台数据：`platform_width_pct`（平台振幅%）、`break_pct`（突破幅度%）、`platform_days`（平台天数）
- 缺口数据：`gap_pct`（缺口幅度%）、`gap_type`（common/breakaway）、`gap_hold_days`（不回补天数）
- 命中标记：`platform_break`（0/1）、`gap_hold`（0/1）、`dual_hit`（0/1）
- 综合分：`pattern_score`
- 基础面：`price / name / change_pct / total_amount / volume_ratio`

### 3.2 指标算法（纯函数，无前视）

**相对波动率窄幅平台 — 修正版（G1，单位统一）**：

原实现两边单位不一致（累计振幅 vs 日均振幅×20），修正为两边统一到日均振幅：
```python
def is_narrow_platform(highs: list, lows: list, platform_days: int = 20,
                       vol_ratio_threshold: float = 0.6) -> tuple:
    if len(highs) < 60 or len(lows) < 60:
        return False, None, None
    mid = (max(highs[-platform_days:]) + min(lows[-platform_days:])) / 2
    if mid <= 0:
        return False, None, None
    # 平台日均振幅 = 平台总振幅 / platform_days（单位：每日振幅）
    platform_daily_range = (max(highs[-platform_days:]) - min(lows[-platform_days:])) / mid / platform_days
    # 近60日历史日均振幅
    daily_ranges = [(h - l) / ((h + l) / 2) for h, l in zip(highs[-60:], lows[-60:]) if (h + l) > 0]
    if not daily_ranges:
        return False, None, None
    avg_daily_range = sum(daily_ranges) / len(daily_ranges)
    is_narrow = platform_daily_range < avg_daily_range * vol_ratio_threshold
    return is_narrow, max(highs[-platform_days:]), min(lows[-platform_days:])
```

**放量突破**：
```python
def is_platform_breakout(closes: list, highs: list, vols: list,
                         platform_days: int = 20, vr_threshold: float = 2.0) -> tuple:
    platform_high = max(highs[-(platform_days + 1):-1])  # 平台上沿（不含今日）
    valid_vols = [v for v in vols[-6:-1] if v > 0]
    vr = vols[-1] / (sum(valid_vols) / len(valid_vols)) if valid_vols else 1.0
    breakout = closes[-1] > platform_high and vr > vr_threshold
    return breakout, platform_high, round(vr, 2)
```

**跳空缺口不回补 — 修正版（G2 breakaway 条件、G3 索引注释）**：

```python
def detect_gap_hold(opens: list, highs: list, lows: list, closes: list,
                    lookback: int = 3, min_gap_pct: float = 0.02,
                    platform_high: float = None, vr: float = None) -> dict | None:
    """
    索引说明（lookback=3）：
      gap_idx = -(lookback+1) = -4  → 3日前的K线（今日=[-1]）
      prev_high = highs[-5]          → 4日前最高价（缺口下沿）
      gap_open = opens[-4]           → 3日前开盘价（跳空高开）
      lows[-3:]                      → 近3日最低价（检查不回补）
    """
    if len(opens) < lookback + 3 or len(highs) < lookback + 3:
        return None
    gap_idx = -(lookback + 1)          # -4：3日前K线
    prev_high = highs[gap_idx - 1]     # -5：4日前最高（缺口下沿）
    gap_open = opens[gap_idx]          # -4：3日前开盘
    if prev_high <= 0:
        return None
    gap_pct = (gap_open - prev_high) / prev_high
    if gap_pct < min_gap_pct:
        return None
    hold = min(lows[gap_idx + 1:]) > prev_high   # 近3日未回补缺口
    # breakaway 三条件：缺口幅度>2% AND 放量(量比>1.5) AND 突破平台上沿（G2）
    is_breakaway = (
        gap_pct > 0.02 and
        (vr is not None and vr > 1.5) and
        (platform_high is not None and gap_open > platform_high)
    )
    gap_type = "breakaway" if is_breakaway else "common"
    return {
        "gap_pct": round(gap_pct, 4),
        "hold": hold,
        "gap_type": gap_type,
        "gap_low": prev_high,
        "gap_hold_days": lookback if hold else 0,
    }
```

### 3.3 调度与 K 线共享缓存（G4）

- 盘后 15:10。
- **K 线共享缓存**：复用 `common.get_kline_cached`（见方案 18 §3.3），同日内与 18/19/21 共享同一批 K 线，东财请求量不翻倍。
- 先粗筛（资金流快照过滤主板 + 成交额 > 5000 万），缩至 ~2000 只；再批量并发 `asyncio.gather + Semaphore(30)`，`return_exceptions=True`。

### 3.4 容错
- K 线拉取失败 → 该票跳过。
- 缺口下沿 prev_high=0 → 防除零。
- 新上市 < 60 日 → 降级不入选。
- 无数据 → `status=no_data` 空态。
