## 1. 目标与定位

顺势选股：每个交易日收盘后，从全市场主板筛选出 **MA 多头排列** 且 **创近 N 日新高** 的强趋势股，作为趋势跟随/追高关注池。逻辑是：均线全多头（趋势健康）+ 价格创新高（强势确认）= 趋势延续概率高。

与现有功能的区别：
- 16 低位涨停是「低位反转」逻辑（跌出来的机会），19 是「高位顺势」逻辑（强者恒强），两者互补。
- 现有 `skill_ma_alignment` 只是多因子评分的一个因子，没有独立的趋势选股池。

优先级：**P0（云端盘后、无本地依赖、K 线现成）**。

## 2. 产品方案

### 2.1 用户场景
每日 15:10 盘后自动跑，15:30 前出结果；次日 09:00 开盘前可查。用户打开「趋势强度选股」页，看到今日 MA 多头 + 创新高的强趋势票，决定次日趋势跟随策略。

### 2.2 菜单归属（智能选股器一级菜单）

本方案（19 趋势强度选股）与方案 18（经典技术指标选股）**统一归属于一级菜单「智能选股器」**下的两个 tab（经典技术指标 / 趋势强度），**不作为独立一级菜单**。

前端结构：
- 导航栏一级菜单「智能选股器」（`data-page="smart-picker"`）。
- 点击后进入智能选股器页，页内 tab 切换：
  - **经典技术指标**（方案 18，数据源 `/api/v1/tech-indicators/latest`）
  - **趋势强度**（本方案 19，数据源 `/api/v1/trend-strength/latest`）
- tab 切换不刷新页面，只切换显示内容；数据通过 SSE 推送 + 60s 轮询实时回显。

### 2.3 页面模块（趋势强度 tab 内）
- **强趋势榜**：按趋势强度分排序，MA 多头 + 创新高命中。
- **🔥 趋势龙头**：同时满足「多头排列 + 创 60 日新高 + 量能放大（量比>1.5）」的票，行首加 🔥 emoji 突出（与 18 的多命中标识一致的视觉优先级）。
- **个股详情**：MA 均线 + 价格走势副图（ECharts）。

### 2.4 筛选条件（默认主板，TREND_* env 可开创业板/科创板）

**市场过滤（复用 `common.market_filter`）**：
- 默认仅主板（剔除 300/301 创业板、688 科创板、ST）。
- `TREND_SHOW_GEM=1` / `TREND_SHOW_STAR=1` 可分别打开创业板/科创板（预留扩展，主板票仍排前）。

**命中条件（AND，两条全过才入选）**：
1. **MA 多头排列**：`MA5 > MA10 > MA20 > MA60`（全部严格大于，含容差 0.5%）。
2. **创 60 日新高**：`现价 > max(closes[-61:-1])`（不含今日的历史最高收盘价）。

**🔥 趋势龙头（加条件）**：上述两条 + **量比 > 1.5**（放量创新高）→ `trend_leader=1`，🔥 突出。

### 2.5 综合分

**trend_score（0-100，供排序）**：
```
trend_score = ma_strength × 50 + new_high_strength × 30 + volume_strength × 20
- ma_strength: 均线乖离度 = (price - MA60) / MA60，越大越强（封顶归一）
- new_high_strength: 新高幅度 = (price - prev_high_60) / prev_high_60
- volume_strength: 量比 = 今日量 / 近5日均量（量比越大越强）
```

### 2.6 输出口径
每只入选票输出：
- 均线值：`ma5 / ma10 / ma20 / ma60`
- 命中标记：`ma_aligned`（0/1）、`new_high`（0/1）、`trend_leader`（0/1）
- `prev_high_60`（60 日历史高点）、`high_break_pct`（突破幅度）
- `volume_ratio`（量比）、`trend_score`
- 基础面：`price / name / change_pct / total_amount`

## 3. 技术方案

### 3.1 数据源
- K 线：`historical_kline.fetch_historical(symbol, days=130)`。
- 全市场基础数据（粗筛）：`fetch_market_fund_flow_resilient`。

### 3.2 指标算法（纯函数，无前视）

**MA 多头排列判定 — 修正版（G1，去掉容差 + 排除横盘）**：

原容差写法在均线粘合期误纳横盘票，修正为严格大于 + 乖离度排除横盘：
```python
def is_ma_aligned(closes: list) -> bool:
    if len(closes) < 60:
        return False
    ma5  = sum(closes[-5:])  / 5
    ma10 = sum(closes[-10:]) / 10
    ma20 = sum(closes[-20:]) / 20
    ma60 = sum(closes[-60:]) / 60
    # 严格多头排列（不用容差）
    if not (ma5 > ma10 > ma20 > ma60):
        return False
    # 排除横盘：MA5 vs MA60 乖离度必须 > 2%，避免均线粘合期误入
    if (ma5 - ma60) / ma60 < 0.02:
        return False
    return True
```

**创 60 日新高判定**：
```python
def is_new_high(closes: list, window: int = 60):
    if len(closes) < window + 1:
        return False, None
    prev_high = max(closes[-(window + 1):-1])  # 不含今日
    return closes[-1] > prev_high, prev_high
```

**量比 — 修正版（G3，过滤停牌日）**：

原实现含停牌日（成交量=0），导致量比虚高：
```python
def volume_ratio(vols: list, window: int = 5) -> float:
    # 过滤停牌日（成交量=0）再取近5日有效均量
    valid_vols = [v for v in vols[-(window + 1):-1] if v > 0]
    if not valid_vols:
        return 1.0
    avg_vol = sum(valid_vols) / len(valid_vols)
    return vols[-1] / avg_vol if avg_vol > 0 else 1.0
```

**MA20 斜率 — 修正版（G4，off-by-one）**：

原 `closes[-25:-5]` 只取 19 根，修正为标准 20 根窗口：
```python
ma20_now  = sum(closes[-20:])   / 20      # 当日 MA20
ma20_prev = sum(closes[-26:-6]) / 20      # 5日前 MA20（20根，终点=-6）
ma20_slope = (ma20_now - ma20_prev) / ma20_prev if ma20_prev > 0 else 0.0
```

**trend_score 百分位归一化（G2）**：

写快照时附加当日相对排名，避免绝对分数跨日不可比：
```python
scores = [r["trend_score"] for r in results]
scores_sorted = sorted(scores)
for r in results:
    rank = scores_sorted.index(r["trend_score"]) + 1
    r["trend_score_pct"] = round(rank / len(scores_sorted) * 100, 1)
```

### 3.3 调度与 K 线共享缓存（G5）

- 盘后 15:10。
- **K 线共享缓存**：复用 `common.get_kline_cached`（见方案 18 §3.3），同日内与 18/20/21 共享同一批 K 线，东财请求量不翻倍。
- 先粗筛（资金流快照过滤主板 + 成交额 > 5000 万），缩至 ~2000 只；再批量并发 `asyncio.gather + Semaphore(30)`，`return_exceptions=True`。

### 3.4 容错
- K 线拉取失败 → 该票跳过。
- 均线窗口不足（新上市 < 60 日）→ 降级不入选。
- 量比分母为 0 → 量比 = 1.0。
- 无数据 → `status=no_data` 空态。

## 12. 修复与优化清单（grill 深挖）

> 本文档为 grill 深挖后补充的修复/优化项，施工时一并纳入。

### 🟡 建议（提升趋势判定可靠性）

1. **MA 多头排列加「斜率方向」判定**
   - 问题：只看均线值大小（ma5>ma10>ma20>ma60），不看均线是否向上。横盘的多头排列（均线走平）是假趋势，向上的多头排列（均线上升）才是真趋势。
   - 建议：加 `ma20[-1] > ma20[-5]`（近 5 日均线向上）判定，确认趋势方向。

2. **均线乖离过峰降权（防超涨误判为强势）**
   - 问题：现价乖离 MA60 超 20~30% 时是"超涨即将回调"，不是"趋势健康"；现状乖离 30% 封顶给满分，把顶部票排最前。
   - 建议：乖离设甜区——5%~15% 加分，>20% 开始降权（`score -= (deviation - 0.20) × 惩罚系数`）。

3. **创新高加「站稳」确认（防假突破）**
   - 问题：单日新高次日回落是典型假突破。
   - 建议：创新高加"收盘站稳"（close > prev_high 且近 2 日都在高点上方），或加"放量新高"（量比>1.5）作为基础命中条件（现量比只在趋势龙头里用，可提到基础命中）。

### 共性修复（18/19/20/21 通用）

- 🔴 **必修 A：阈值/权重无样本校准**。MA 容差 0.5%、新高窗口 60、量比 1.5 等全是经验初值。上线后积累 60~200 交易日样本，把因子值落库喂给 **06 因子实验室**，做 IC/IR 归因，反向校准阈值与指标权重。
- 🟡 **建议 B：K 线当日缓存 + 粗筛缩圈**。全主板 3194 只拉 K 线 ~5min，改为：① K 线当日缓存复用（盘中 5min 循环不重复拉，对齐 17 模式）；② 先用资金流快照粗筛（主力净流入>0，缩至 ~1000~1500 只），耗时减半。
- 🟢 **可选 C：盘中 5min 实时化**。盘后日频改为盘中 5min 循环，用当日实时价替换最后收盘价重算指标（复用 17 的 `d2_score_intraday` 模式），实现"盘中趋势实时选股 + 涨前推送"。
