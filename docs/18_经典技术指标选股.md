## 1. 目标与定位

把 A 股散户/游资最常用的四大经典技术指标（MACD/KDJ/RSI/BOLL）落地为「盘后选股」：每个交易日收盘后，从全市场主板筛选出 **金叉启动** 或 **超卖反弹** 的候选票，作为次日重点关注池。

与现有功能的区别：
- 现有系统强在「资金流/涨停/盘口/板块/四维共振」维度，**缺经典技术指标维度**（现有只有 MA，无 MACD/KDJ/RSI/BOLL）。
- 本方案补盲：技术指标选股是 A 股最流行的选股方式之一，门槛低、认知广、可直接对照通达信/同花顺口径。

优先级：**P0（云端盘后、无本地依赖、K 线现成）**。

### 2.5 综合分与多命中标识

**tech_score（0-100，供排序）**：
```
tech_score = hit_count(命中指标数) × 25 + strength_bonus(强度加权)

- strength_bonus: MACD 金叉力度 + KDJ 低位深度 + RSI 超卖深度 + BOLL 反弹幅度，各 0-5 加权
```

**多命中标识（multi_hit）**：命中 ≥ 2 个指标 → `multi_hit=1`：

- **邮件**：多命中票排在最前，标题带 `🔥 多指标共振 ×N`；正文多命中票行首加 🔥。
- **排序**：tech_score 降序（多命中天然排前）。

### 2.6 输出口径
每只入选票输出：

## 3. 技术方案

### 3.1 数据源
- K 线：`backend/agents/layer1_data_collector/sources/historical_kline.py::fetch_historical(symbol, days=130)`，返回 `日期/开盘/收盘/最高/最低/成交量/涨跌幅/换手率`。
- 全市场基础数据（粗筛）：`fetch_market_fund_flow_resilient`（`price/total_amount/change_pct`），避免全量拉 K 线。

### 3.2 指标算法（纯函数，无前视）

> 全部指标只用「当日及之前」数据，无前视偏差。`closes/highs/lows` 为历史序列（`closes[-1]` 为最新收盘）。
> ⚠️ 实际施工以 `backend/plugins/tech_indicators/indicators.py` 中已实现的 `compute_macd / compute_kdj / compute_rsi / compute_boll / compute_tech_score` 为准，本节对齐通达信口径的修正点已标注。

**EMA（指数移动平均）— 通达信口径修正（G1）**：

原实现用 `vals[0]` 作种子，与通达信偏差最多 5%。修正为前 `period` 根 SMA 作种子：
```python
def ema_series(values: list, period: int) -> list:
    vals = _closes(values)
    if len(vals) < period:
        return []
    # 通达信口径：前 period 根的 SMA 作起点，不用第一根收盘价
    seed = sum(vals[:period]) / period
    k = 2.0 / (period + 1)
    out = [seed]
    for v in vals[period:]:
        out.append(v * k + out[-1] * (1 - k))
    return out
# 注意：返回序列长度 = len(vals) - period + 1，compute_macd 中 zip 对齐需对应调整
```

**MACD（12, 26, 9）**：
```python
# ema_fast/ema_slow 长度对齐后做差
dif_series = [f - s for f, s in zip(ema_fast[-len(ema_slow):], ema_slow)]
dea_series = ema_series(dif_series, 9)
golden = dif_series[-2] < dea_series[-2] and dif_series[-1] >= dea_series[-1]
```

**KDJ（9, 3, 3）— 通达信口径修正（G2）**：

原 `_sma_recursive` 用 `rsv_series[0]` 作种子，初始 K/D 与通达信偏差大。修正为种子=50：
```python
def _sma_recursive(rsv_series: list, period: int, weight: float = 1.0, seed: float = 50.0) -> list:
    """通达信口径：K/D 初始值均为 50，递推平滑。"""
    out = [seed]
    for v in rsv_series:
        out.append((weight * v + (period - weight) * out[-1]) / period)
    return out[1:]  # 去掉 seed，返回与 rsv_series 等长的序列
```

**RSI（14）**：
```python
# avg_loss=0 → RSI=100（防除零已实现）
rsi_oversold = rsi < 30 and rsi_prev is not None and rsi > rsi_prev
```

**BOLL（20, 2）— 反弹条件修正（G3）**：

原条件"昨触下轨今穿中轨"在主板几乎不触发。修正为接近实盘的定义：
```python
ma5_now = sum(vals[-5:]) / 5
rebound = (
    lb_prev is not None and
    vals[-2] <= lb_prev and      # 昨日收盘触及下轨
    vals[-1] > vals[-2] and      # 今日收盘高于昨日（有效反弹）
    vals[-1] > ma5_now           # 今日收盘站上5日均线（动量确认）
)
```

**tech_score（综合分）— 强度公式已落实（G4）**：

`compute_tech_score` 中的强度加权已有具体公式（见代码），文档对齐：
```
score = min(4, hit_count) × 25
      + MACD 金叉力度：min(5, |histogram| × 2)
      + KDJ 低位深度：min(5, (20 - k) / 4)
      + RSI 超卖深度：min(5, (30 - rsi) / 6)
      + BOLL 反弹固定加分：3.0
```

**分数百分位归一化（G8）**：

写快照时在结果列表上附加当日相对排名，供前端展示"今日排名前 X%"：
```python
scores = [r["tech_score"] for r in results]
scores_sorted = sorted(scores)
for r in results:
    rank = scores_sorted.index(r["tech_score"]) + 1
    r["tech_score_pct"] = round(rank / len(scores_sorted) * 100, 1)
```

### 3.3 调度与 K 线共享缓存（G5）

- 盘后 15:10（随 daily-screening cron 或独立 cron）。
- **K 线共享缓存**：18/19/20/21 四个插件复用同一次 K 线批量拉取，避免重复请求东财：
  ```python
  # backend/plugins/common.py 新增
  _kline_cache: dict = {}   # {code: bars}
  _kline_cache_date: str = ""

  async def get_kline_cached(code: str, days: int = 130) -> list:
      from backend.plugins.common import BEIJING_TZ
      today = datetime.now(BEIJING_TZ).strftime("%Y-%m-%d")
      global _kline_cache_date
      if _kline_cache_date != today:
          _kline_cache.clear()
          _kline_cache_date = today
      if code not in _kline_cache:
          _kline_cache[code] = await fetch_historical(code, days=days)
      return _kline_cache[code]
  ```
- 调度层先粗筛（资金流快照过滤主板 + 成交额 > 5000 万），缩至 ~2000 只；再批量并发 `asyncio.gather + Semaphore(30)`，`return_exceptions=True`，预计 ~50s（四插件共享后无倍增）。

### 3.4 容错
- K 线拉取失败 → 该票跳过，不阻断整体。
- HHV=LLV（一字板）→ RSV 降级 50；avg_loss=0 → RSI=100；STD=0 → BOLL 降级。
- 无数据 → `status=no_data` 空态，不伪造指标值。

   - 修复：`_rsi_series()` 改用 Wilder 递推——首值用前 14 日均值初始化，之后 `avg_gain = (prev_avg_gain × 13 + gain) / 14`、`avg_loss = (prev_avg_loss × 13 + loss) / 14`。

2. **KDJ 初始 K/D 值改用 50**（替代 `rsv[0]`）
   - 现状问题：`_sma_recursive` 第一行 `out = [rsv_series[0]]`，初始 K 用第一个 RSV，序列前段偏离标准 KDJ。
   - 修复：`_sma_recursive` 加 `initial=50.0` 参数，K/D 都用 50 初始化（标准 KDJ 口径）。

### 🟡 建议（提升命中可靠性）

3. **MACD 金叉区分「0 轴上方/下方」**
   - 问题：0 轴上方金叉（强势启动）和 0 轴下方金叉（弱势反弹/假金叉）可靠性差很多，现状不区分。
   - 建议：加 `golden_above_zero`（dif>0 时金叉，标强势，提权）和 `golden_below_zero`（dif<0 时金叉，降权或标注"弱势"）。

4. **BOLL「触下轨」用 low 而非 close，反弹放宽**
   - 问题：现价收破下轨是"弱势击穿"，不是"触碰反弹"；现状 `closes[-2] <= lb_prev` 口径偏弱。
   - 建议：触下轨改用 `lows[-2] <= lb_prev`（最低价触及）；反弹放宽为 `closes[-1] > closes[-2]`（回升即可，不强制站上中轨）。

5. **tech_score 指标加权**（替代均分 hit_count × 25）
   - 问题：4 个指标可靠性不同（MACD > KDJ > BOLL），均分不区分。
   - 建议：加权 `MACD 30 + KDJ 25 + RSI 25 + BOLL 20`；上线后用 06 因子实验室 IC 数据反推权重。

### 🟢 可选（锦上添花）

### 共性修复（18/19/20/21 通用）

- 🔴 **必修 A：阈值/权重无样本校准**。MACD 金叉、KDJ<20、RSI<30 等全是经验初值。上线后积累 60~200 交易日样本，把因子值落库喂给 **06 因子实验室**，做 IC/IR 归因，反向校准阈值与指标权重。
- 🟡 **建议 B：K 线当日缓存 + 粗筛缩圈**。全主板 3194 只拉 K 线 ~5min，改为：① K 线当日缓存复用（盘中 5min 循环不重复拉，对齐 17 模式）；② 先用资金流快照粗筛（主力净流入>0，缩至 ~1000~1500 只），耗时减半。
- 🟢 **可选 C：盘中 5min 实时化**。盘后日频改为盘中 5min 循环，用当日实时价替换最后收盘价重算指标（复用 17 的 `d2_score_intraday` 模式），实现"盘中指标实时选股 + 涨前推送"。
