# 02 龙虎榜与席位画像 — 产品开发技术方案

## 1. 目标与定位

解决“只看到涨停，不知道谁在买”的问题。建立龙虎榜每日数据 + 席位画像库，输出：
- 每日上榜原因、买卖前五席位、净买额、机构/沪股通/知名游资标记；
- 席位历史胜率、偏好板型、偏好题材、协同席位；
- 个股被哪些席位反复做、机构净买连续性。

优先级：P0。数据免费可得、准确率可控，是机构资金跟踪与短线跟庄参考的刚需。

## 2. 产品方案

### 2.1 页面模块
- 每日龙虎榜：按净买额 / 上榜原因 / 席位类型筛选。
- 席位详情：胜率、T+1/T+3/T+5 平均收益、近期活跃度、偏好板型、协同席位网络。
- 个股详情：历史龙虎榜、机构净买连续性、知名游资进出。

### 2.2 输出口径
- 席位胜率 = 该席位历史买入上榜后 T+1/T+3/T+5 正收益占比。
- 偏好板型 = 首板 / 连板 / 反包 / 断板反包分布。
- 协同席位 = 同榜共现频率 Top-N。

## 3. 技术方案

### 3.1 数据源
- 东方财富龙虎榜接口（datacenter / push2）为主。
- akShare `stock_lhb_detail_em` 兜底。
- Tushare `top_list` / `top_inst` 回补历史。

### 3.2 席位归一化
- 去空格、括号、去“证券营业部”后缀。
- 识别“机构专用”“沪股通专用”“深股通专用”及常见量化席位模式。
- 归一化置信度写入 `match_confidence`，低置信度不自动合并。

### 3.3 画像算法
- 席位胜率：按席位聚合历史样本，滚动窗口统计正收益占比。
- 偏好板型 / 题材：对历史上榜日股票标签做频率分布。
- 协同网络：同榜共现矩阵，保留 Top-N。
- 资金质量分 = 机构净买 + 知名游资接力 + 连板高度低的加权分，可作为主力资金因子增强项。

### 3.4 调度
- 盘后每日一次，跟随 daily-screening 或独立 cron。
- 席位画像盘后物化重算，页面不实时算。

## 4. 数据存储方案

```sql
CREATE TABLE lhb_daily (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,
  code TEXT NOT NULL,
  name TEXT,
  reason TEXT,
  net_buy REAL,
  buy_inst INTEGER,
  sell_inst INTEGER,
  lhb_type TEXT
);
CREATE INDEX idx_lhb_date ON lhb_daily(date);
CREATE INDEX idx_lhb_code_date ON lhb_daily(code, date);

CREATE TABLE lhb_seats (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,
  code TEXT NOT NULL,
  seat_name TEXT NOT NULL,
  normalized_name TEXT,
  side TEXT,
  amount REAL,
  seat_type TEXT,
  match_confidence REAL
);
CREATE INDEX idx_lhb_seats_date ON lhb_seats(date);
CREATE INDEX idx_lhb_seats_norm ON lhb_seats(normalized_name);

CREATE TABLE seat_stats (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  seat_name TEXT UNIQUE NOT NULL,
  win_rate_t1 REAL,
  win_rate_t3 REAL,
  win_rate_t5 REAL,
  avg_return REAL,
  prefer_board TEXT,
  prefer_theme TEXT,
  updated_at TEXT
);
```

物化快照：`reports/lhb_latest.json` + `reports/data_backend/lhb_latest.json`。

## 5. 数据读取方案

- `GET /api/v1/lhb/latest?date=&reason=&seat_type=`：读 JSON 快照。
- `GET /api/v1/lhb/seat/{normalized_name}`：走 `seat_stats` 预计算画像。
- `GET /api/v1/lhb/stock/{code}`：走 `idx_lhb_code_date`。

页面首屏秒开，明细按需加载。

## 6. 与现有系统集成

- 新增 `backend/plugins/lhb_seat/`，复用 `principal_capital` 的市场过滤、邮件、去重范式。
- `main.py` 注入 router + `--run-lhb-once`。
- 龙虎榜信号可作为 `principal_capital` 或主筛选的加分因子，先旁路观察，稳定后再进生产展示。

## 7. 测试与验收

- 席位归一化测试：同一营业部不同写法合并为同一 normalized_name。
- 胜率口径测试：无前视，只使用上榜日之前数据。
- 验收：近 30 个交易日龙虎榜无缺日，席位画像可解释。

## 8. 上线与运维

- 独立 GitHub Actions cron 或并入 daily-screening。
- 龙虎榜生成物提交 `data-snapshots` 分支。

## 9. 风险与限制

- 营业部改名 / 席位合并会导致画像误差，需人工维护映射表。
- 龙虎榜只覆盖上榜股，不能代表全市场资金行为。
- 历史收益仅统计相关性，不构成投资建议。

## 10. 里程碑

1. M1：龙虎榜采集 + `lhb_daily/lhb_seats` 落库。
2. M2：席位归一化 + 画像统计。
3. M3：页面 + 信号旁路接入。
