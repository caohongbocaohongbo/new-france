# 08 逐笔成交行为分析 — 产品开发技术方案

## 1. 目标与定位

对标 Level-2“逐笔成交”页，但明确标注为**分钟级近似**：
- 主动买 / 主动卖 / 中性单占比；
- 大单、超大单成交占比；
- 连续同向攻击（连续多笔主动买推升）；
- 大单拆单识别（同一分钟多笔小单同向、合计额大）；
- 对倒 / 倒仓嫌疑（买卖交替、价格不动、量异常）。

优先级：P0。pytdx 逐笔数据已在，只缺行为聚合。

## 2. 产品方案

### 2.1 页面模块
- 逐笔行为榜：观察池按主动买强度 / 大单占比排序。
- 个股分钟级订单流：buy_vol / sell_vol / neutral_vol / large_buy / large_sell。
- 异常事件：连续攻击、疑似拆单、疑似对倒。

### 2.2 输出口径
- 单笔金额 = price × vol × 100。
- 大单阈值：单笔 ≥ 20 万（可配置）；超大单 ≥ 100 万（可配置）。
- 连续攻击：窗口内连续 `buyorsell=0` 且价格向上的笔数 / 累计金额。
- 拆单识别：同一分钟、方向一致、单笔 < 大单阈值、合计 ≥ 大单阈值。

## 3. 技术方案

### 3.1 数据源
- `tdx_source.TdxPool.fetch_stock` 返回的 `txs`（price / vol / buyorsell / num）。
- `num` 单调递增用于增量去重，`RadarStore.update_transactions` 已实现。

### 3.2 算法
- 分钟桶聚合：按 `time` 桶内汇总 buy/sell/neutral 量与金额。
- 大单 / 超大单：单笔金额分档。
- 连续攻击：滑动窗口内统计连续同向笔数与累计额。
- 拆单：同分钟同方向多笔小单合并判断。
- 对倒嫌疑：同分钟买卖交替、净量≈0、价格波动小、成交量异常。

### 3.3 限制说明
- pytdx 逐笔 `time` 只有分钟级，无法秒级排序；只做分钟桶聚合 + `num` 排序近似。

## 4. 数据存储方案

- 逐笔原始数据只本地落 `data/tick_raw_{date}.parquet`，不上传 Render。
- 实时聚合表：

```sql
CREATE TABLE orderflow_features (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,
  code TEXT NOT NULL,
  minute TEXT NOT NULL,
  buy_vol REAL,
  sell_vol REAL,
  neutral_vol REAL,
  large_buy REAL,
  large_sell REAL,
  attack_buy_count INTEGER,
  split_large_flag INTEGER
);
CREATE INDEX idx_orderflow ON orderflow_features(date, code, minute);
```

- 聚合结果写 `reports/orderflow_latest.json`。

## 5. 数据读取方案

- `GET /api/v1/smart-money-radar/orderflow/latest`：读 JSON。
- `GET /api/v1/smart-money-radar/orderflow/{code}?date=`：本地读分钟级聚合。
- 逐笔原始数据只本地研究页面可见，云端不暴露。

## 6. 与现有系统集成

- 在 `smart_money_radar` 内新增 `orderflow.py`，复用 `RadarStore.minute_buckets`。
- 事件合并进雷达邮件，冷却去重复用 `should_notify`。

## 7. 测试与验收

- 去重测试：两轮重叠只吃新 `num`。
- 大单 / 拆单 / 对倒识别测试，边界防除零。
- 验收：分钟级聚合正确、原始逐笔不泄露到 Render。

## 8. 上线与运维

- 本地常驻，Parquet 按日保留 N 天，过期清理。
- 若本地磁盘紧张，可关闭 `enable_sqlite_dump` / 缩短保留。

## 9. 风险与限制

- 非毫秒级逐笔，时间排序能力有限；不能替代真 L2。
- 集合竞价伪 bar（vol ≈ 0）必须过滤（已在 `indicators._valid_bars` 处理）。

## 10. 里程碑

1. M1：分钟桶聚合 + 大单分档。
2. M2：连续攻击 / 拆单 / 对倒识别。
3. M3：本地明细 + 云端快照。
