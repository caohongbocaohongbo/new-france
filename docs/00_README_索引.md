## 复用原则（14 个方案通用）

- 新增功能一律采用独立 `backend/plugins/<plugin>/` 目录，参考 `principal_capital` / `smart_money_radar` 范式。
- `backend/main.py` 只做 try/except 可选加载与 CLI 分发，保持主链路零污染。
- 页面数据只来自后端真实接口，前端不渲染本地假数据。
- 高频盘口/逐笔原始数据只落本地，不提交 Render；云端只同步聚合 JSON 快照。
- 外部请求必须带 timeout，独立请求用 `asyncio.gather` + Semaphore 并发，时间统一 `BEIJING_TZ`。
- 数据快照沿用 `data_backend` 与 GitHub `data-snapshots` 分支，Render 拉不到东财时读 raw JSON 兜底。
